# Welcome to the Megastructure Archive

This is your personal note repository, running inside the megastructure. Drop any `.md` files from your Obsidian vault into the `notes/` directory at the project root and they will appear here on restart.

## Features

- **Wiki links** — [[Getting Started]] navigates between notes  
- **Folder support** — organises notes by subdirectory  
- **Search** — filter by filename using the sidebar  
- **YAML frontmatter** — title and tags parsed automatically  
- **Task lists**, tables, code blocks, blockquotes
